Contribute Code on GitHub

Help improve the open source Pushti Kirtan project.

PushtiKirtan.com is open source so Vaishnav developers and technically skilled volunteers can help preserve, improve, and expand this devotional archive. If you can code, design, test, optimize, document, or improve search visibility, your skills can become meaningful seva.

View on GitHub

Ways to Help

  • Improve search, filtering, pagination, and reading flows.
  • Enhance SEO for kirtan, raag, occasion, and archive pages.
  • Polish responsive UI details for mobile, tablet, and desktop.
  • Improve accessibility, semantic HTML, structured data, and performance.
  • Fix bugs in admin, contributor, social sharing, and public browsing workflows.
  • Add tests, documentation, setup guides, and safer developer tooling.

Good First Contributions

Small, careful improvements are welcome. A good first pull request might fix a mobile layout issue, improve documentation, simplify a script, add a missing empty state, improve Lighthouse scores, or make a confusing workflow easier to understand.

How to Contribute

  1. Visit the project on GitHub and review the README.
  2. Fork the repository and create a focused branch for your change.
  3. Run the project locally and test your update carefully.
  4. Open a pull request with a clear description of what changed and why.

Please keep pull requests focused and respectful of the devotional purpose of the site. Changes should make the archive more accurate, useful, beautiful, accessible, or maintainable. If you have any questions before contributing, please email support@pushtikirtan.com.

Voluntary Contribution

Code contributions to PushtiKirtan.com are voluntary and unpaid. This open source work is offered as seva to help preserve and improve access to Pushtimargiya kirtans for the Vaishnav community.

Project Spirit

This is a community archive, built with care for Pushtimargiya kirtans and the Vaishnavs who read them. The goal is not just more code, but better preservation, better reading, and better access for future generations.
